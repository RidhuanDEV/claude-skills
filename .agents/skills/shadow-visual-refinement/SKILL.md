# Shadow Visual Refinement

Read the [visual refinement review](../../../shadow-design/references/visual-refinement-review.md) from this workspace. It contains the procedure and attribution.

Use the intended task and current screen state to identify the cue that should stand out. Report the competing cue, its effect on the task, and the smallest justified change. Preserve intentional emphasis that helps the user.

For a review request, return findings without editing. For an authorized refinement, compare the same state and viewport before and after. Check that the main action and related recovery remain reachable by keyboard. Report observations separately from predicted usability gains.
