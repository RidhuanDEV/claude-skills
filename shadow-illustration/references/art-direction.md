# Art direction for illustration families

1. Write the job of each image in one sentence. An empty state might show how to add the first item. A failure image should support the recovery text and action.
2. Audit existing design tokens and collect approved examples. Record theme, stroke and texture, shape language, proportion, palette, tonal range and background treatment in a short style card.
3. Pick a visual language appropriate to the job. Flat/geometric art uses clear shapes and value groups. Editorial art can introduce metaphor. Isometric art needs consistent projected axes. Painterly work depends on texture and lighting. Pixel art depends on a fixed grid and constrained detail.
4. Sketch alternate silhouettes or layouts before rendering detail. Compare the clearest candidate at actual placement. Use the reviewed version as master, and keep a contact sheet for later states.
5. For each scene record stable elements, allowed variation, focal point, lighting and intended emotional intensity. Use gesture, shape and expression as well as status color.

Typical failure modes include overworked backgrounds, repeated hand poses for unrelated states, or style drift caused by directing each render independently. Compare like-for-like crops and amend the specific drift. Record visual review from actual images and any unresolved difference.
