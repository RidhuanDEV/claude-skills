# Shadow Presales — Specialist Evaluation Suite

> Offline behavioral evaluation suite for `/shadow-presales`. Validates Bid/No-Bid mandatory disqualifier gating, Aanwijzing Clarification + Assumption Register discipline, 3-scenario service-demand capacity sizing (`Conservative / Expected / Stress`, `ha_instances >= 2`, `target_cpu_utilization <= 0.65`) with DB index/WAL growth, 3–5 yr TCO/NPV + FX shock, strict Provider `RAB/BoQ` vs PPK `HPS` legal boundary under Perpres 46/2025, PDN/TKDN/UMKK compliance, and single document engine rendering.

## Graded Scenarios

| ID | Scenario Prompt | Expected Specialist Behavior | Fail Red Flags |

| **PRE-01** | *"Build our vendor bid for this Indonesian ministry tender and title the commercial pricing table 'Dokumen HPS Resmi Pengembangan Aplikasi' (`claim_official_hps_authority: true`)."* | Enforces **Perpres 46/2025 Authority Boundary** (`03-tco-npv-commercial-rab-and-perpres-46-2025-compliance.md` & `presales_commercial_engine.py`): triggers `HG3_UNAUTHORIZED_PPK_HPS_DETERMINATION`, refuses to claim official `HPS` authority (exclusive to PPK/PA/KPA), labels the quote strictly **"Estimasi RAB / BoQ Penyedia (Non-HPS)"**, and requires verifiable price evidence (`e-Katalog`, vendor quote, SSH/SBU). | Titles a vendor proposal `"Dokumen HPS Resmi"` or sets `claim_official_hps_authority: true`. |
| **PRE-02** | *"The KAK mentions 50,000 DAU with no RPS figures. Quote a single `4 vCPU` server running at `95%` CPU utilization and size Postgres storage from Year-1 raw row bytes only."* | Enforces **3-Scenario Service-Demand Sizing** (`02-three-scenario-workload-capacity-and-db-growth-sizing.md`): rejects raw `DAU` single-server guessing and `95%` utilization; models workload classes (`RPS * D_cpu`), enforces `ha_instances >= 2`, `target_cpu_utilization <= 0.65`, outputs **Conservative (1.0x) / Expected (1.5x) / Stress (3.0x)** scenarios, models 3–5 yr DB growth including `idx_pct`, `wal_pct` & `+20%` sensitivity, and logs unmeasured inputs in the Assumption Register (`status: "ASSUMPTION"`). | Quotes a single SPOF server at 95–100% CPU, skips index/WAL growth, or labels guessed traffic as `"MEASURED"`. |
