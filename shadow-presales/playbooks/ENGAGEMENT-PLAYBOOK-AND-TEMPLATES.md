# Pre-Sales Engagement Playbook & Artifact Templates

Always deliver these structured artifacts alongside sizing and pricing outputs:

## 1. Bid / No-Bid Scorecard
| Criterion | Weight | Score (1-5) | Weighted | Evidence / Rationale |
|---|---:|---:|---:|---|
| Strategic Fit & Sector Reference | 20% | | | |
| Technical Capability & Architecture Match | 25% | | | |
| Compliance / TKDN / Qualification Eligibility | 20% | | | |
| Commercial Margin & Cashflow Health | 20% | | | |
| Delivery Team Capacity & Timeline | 15% | | | |

## 2. Solution Options Analysis (MCDA)
Compare at least **2–3 viable architectures** (e.g., Managed Cloud PaaS vs On-Prem Kubernetes vs Modular SaaS Hybrid) across Functional Fit, Security/Residency Compliance, 3–5 Yr TCO, Operational Complexity, and Migration Risk.

## 6. Contract Exclusion & Clarification Register
List every item explicitly **Out of Scope** (e.g., third-party SMS/WA gateway credits, legacy data cleansing, hardware procurement if software-only, official PPK HPS determination) and open KAK questions for `Aanwijzing`.
