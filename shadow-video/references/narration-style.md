# Narration style (Indonesian TTS)

The narration is read by Azure neural voices (`id-ID-GadisNeural`, `id-ID-ArdiNeural`). These rules make every
agent produce the same tone and the same TTS behaviour. `tools/naskah.py` enforces the mechanical ones (`lint`).

## Mechanical rules (enforced)

- No digits or symbols in narration: `0-9 / & + ( ) >`, no emoji. Write numbers as words ("tiga langkah").
- Maximum 20 words per sentence; one idea per sentence.
- Abbreviations are spelled with hyphens so TTS reads letters: `N-I-K`, `N-I-D-N`, `P-D-F`, `O-T-P`, `Q-R Code`.
  Common words that TTS reads correctly as words stay as they are (Monev, Excel, email if the project uses it).

## Voice and register

- Follow the project's existing address form. Formal institutional apps (universities, ministries) use "Anda";
  consumer apps may use "kamu". Pick one per project, record it in the template README, never mix.
- Educational, not mechanical: say what a feature is for and when to use it, not only "klik tombol".
  Weak: "Klik tombol Simpan." Better: "Klik Simpan Draf. Usulan tersimpan dan dapat dilanjutkan kapan saja."
- Name UI elements exactly as their visible label, without quotes or symbols ("tombol Masuk ke portal").
- No filler openers ("Baiklah", "Nah", "Oke"), no hype ("sangat mudah", "canggih").

## Continuity across modules

All modules are also joined into one long video, so:

- Opening of each module: "Pada bagian ini, ..." The welcome sentence appears only in the first module.
- Closing of each module: a transition such as "Selanjutnya, kita akan ...". Never "di video berikutnya" or
  "sampai jumpa". Thanks appear only in the last module.

## Demonstrate, then explain

Every feature that is narrated is shown: open it, explain while it is visible, close it. A tooltip, a password eye
icon, a modal, a dropdown: the cursor goes there. A feature that cannot be shown safely (an inbox, a captcha, a
real password) is narrated as an instruction ("periksa kotak masuk dan folder spam") and is not displayed.

## Script table format (`tutorial/NN-*.md`)

Generated by `write_module`:

```
# NN - Judul Modul
## INFORMASI MODUL            Tujuan Pembelajaran, Target Aktor, Tampilan Antarmuka, URL Halaman, Data Demo
## TABEL NASKAH SCENE & AKSI LAYAR
| No Scene | Aksi di Layar | Tampilan Visual Layar | Naskah Narasi Suara (TTS Bahasa Indonesia) | Durasi (detik) |
## SUMBER TEKS UI (kode adalah sumber kebenaran)   one line per label group with file:line
## CATATAN PRODUKSI           differences from the request, risks, what to check on staging
```

Duration estimate: words / 2.3 per second at `TTS_RATE=+0%`. A scene lasts `max(action time, audio) + 300 ms`.

## Review checklist before asking for approval

- [ ] `python tools/build-NN.py` prints `ok` (lint passed, ids unique, sources present).
- [ ] Every label in the narration exists in the cited source lines.
- [ ] Opening and closing follow the continuity rule.
- [ ] Nothing in the narration reveals a credential, token, personal data, or a local path.
