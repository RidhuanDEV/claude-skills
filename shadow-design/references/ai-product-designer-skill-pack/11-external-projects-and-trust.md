# Curated external resources (optional, NOT bundled)
These are upstream projects/docs to *read and evaluate*. This package contains no third-party source copies or preinstalled MCPs. Check each project's current license, commit, dependencies and permissions before installing.

- Design with Intent: https://github.com/ghaida/intent — discovery, experience design, evaluation, hardening, accessibility, handoff. Suggested first design reasoning reference.
- UX Flow Skills: https://github.com/jpoindexter/ux-flow-skills — forms, auth, tables, search, error, AI-chat flow patterns; MIT listed.
- PM Skills: https://github.com/phuryn/pm-skills — product management discovery and strategy; MIT listed.
- UI UX Pro Max: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill — visual design conventions; consult *after* flow modeling.
- Designer Skills: https://github.com/Owl-Listener/designer-skills — modular research, accessibility, interactions, evaluation.
- Penpot MCP: https://github.com/penpot/penpot/blob/develop/mcp/README.md — optional editable canvas; MCP plugin supports script execution in Penpot context: review privileges carefully.
- Excalidraw MCP: https://github.com/excalidraw/excalidraw-mcp — optional editable flow diagrams; review local vs remote processing, dependencies and data exposure.
- Agent Skills standard: https://agentskills.io/specification — packaging rules.
- WCAG 2.2: https://www.w3.org/TR/WCAG22/
- Nielsen's usability heuristics: https://www.nngroup.com/articles/ten-usability-heuristics/

## Installation trust tiers
T0: Read-only links for methodology (default). T1: Vendor-authored markdown skill copied after license review and inspection. T2: Third-party scripts/dependencies (review lockfiles, code, lifecycle hooks, execution sandbox). T3: MCP with data access/write or remote service (permission inventory, scoped tokens, explicit consent, privacy review, audit logs). Do not claim any upstream is 'safe' without a current audit of the exact version and deployment.
