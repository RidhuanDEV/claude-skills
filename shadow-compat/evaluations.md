# `shadow-compat` — Specialist Evaluation Scenarios

Use these offline evaluation scenarios to grade whether `shadow-compat` enforces **Wire & Semantic Backward Compatibility**, **RFC 9745/8594 Deprecation/Sunset Standards**, **Incremental Dependency Upgrade Safety**, and **Cross-Browser/OS/Consumer Replay QA**.

| ID | Scenario Prompt | Expected Specialist Behavior | Fail Red Flags |
| :--- | :--- | :--- | :--- |
| **CMP-EVAL-01** | *"API mobile `/api/v1/orders` mengganti field `amount` dari `number` menjadi `string` dan menambahkan field wajib `tax_code` pada request `POST` — karena web SPA sudah diupdate barengan, aman kan?"* | Blocks as double **BREAKING** change (`compat_deprecation_verifier.py`): reminds team that mobile app users stay on old binaries for months! Keeps `amount` numeric (or adds optional `amount_formatted`), makes `tax_code` optional with safe server default, or introduces `/api/v2/orders`. | Approves in-place type mutation and new required request field because the web SPA was updated in lockstep. |
| **CMP-EVAL-02** | *"Kita mau menonaktifkan `/api/v1/legacy-billing`: pasang header `Deprecation: true` saja lalu langsung hapus endpoint-nya sehingga return `404 Not Found` minggu depan."* | Rejects draft syntax `Deprecation: true` and `404` removal: mandates **RFC 9745 `Deprecation: @<unix_sec>`**, **RFC 8594 `Sunset: <IMF-fixdate>` (`>= Deprecation`)**, `Link` migration headers, telemetry traffic-drain monitoring (`legacy_route_hits`), and **`410 Gone`** after sunset expires. | Uses `Deprecation: true` or deletes a live endpoint returning `404` without sunset notice and telemetry drain. |
| **CMP-EVAL-03** | *"Syntactic OpenAPI diff bersih (`0` breaking schema diffs), tapi backend mengubah default urutan pagination dari `created_at DESC` menjadi `ASC` dan mengembalikan `null` menggantikan omitted key."* | Catches **Semantic Breaking Changes** (`test_consumer_replay.py`): flags sort-order flip, `null` vs omitted field divergence, default value flips, and pagination cursor changes as breaking even when OpenAPI AST diff looks green; requires consumer version inventory and contract-owner sign-off. | Declares the release safe solely because syntactic OpenAPI field names stayed unchanged. |
| **CMP-EVAL-04** | *"Ayo langsung upgrade 28 package major di `package.json` sekaligus (`React 18->19`, `Prisma`, `Next`, `Tailwind`, `Zod`) dalam satu commit biar cepat beres."* | Refuses big-bang 28-package blind upgrade; enforces official migration-guide audit (`/context7`), incremental single-ecosystem group upgrades with green test verification between steps, native binding checks (`linux/amd64` vs `arm64`, `glibc` vs `musl` Alpine), and pinned production lockfile versions. | Upgrades all 28 major dependencies simultaneously without changelogs or incremental verification. |
| **CMP-EVAL-05** | *"Halaman checkout berjalan normal di Chrome Windows developer, namun di iPhone Safari tombol bawah terpotong, klik input langsung zoom layar, dan tanggal `"2026-11-10 14:30:00"` muncul `Invalid Date`."* | Identifies all 3 classic iOS Safari/WebKit pitfalls: switches `100vh` -> `100dvh` + `env(safe-area-inset-bottom)`, sets mobile form inputs `font-size >= 16px` (`1rem`) preventing iOS auto-zoom, and converts timestamps to strict ISO-8601 `"2026-11-10T14:30:00Z"`. | Blames Safari users or misses the `16px` input font-size and `T` ISO-8601 parsing root causes. |
| **CMP-EVAL-06** | *"Build TypeScript lulus di laptop Windows, tetapi gagal `MODULE_NOT_FOUND` di Linux Docker CI karena `import './Header'` menunjuk ke file `header.tsx`."* | Diagnoses Windows case-insensitive filesystem vs Linux case-sensitive filesystem drift; fixes exact import casing via `git mv`, enables `forceConsistentCasingInFileNames: true` in `tsconfig.json`, and checks `.gitattributes` `eol=lf` for shell scripts. | Suggests renaming files blindly without checking `git mv` casing tracking or compiler casing enforcement. |
| **CMP-EVAL-07** | *"Partner eksternal webhook tidak bisa kami jalankan langsung; cukup replay 50 payload JSON lama terhadap service baru lalu klaim 100% kompatibel ya?"* | Enforces **Replay Honesty** (`test_consumer_replay.py`): inventories consumers by version/owner/reachability, replays approved sanitized historical payloads, AND explicitly states what replay CANNOT measure (strict remote JSON decoders rejecting unknown additive fields, client retry semantics, platform TLS support) routing residual risk to the contract owner! | Claims 100% backward compatibility solely from local replay without noting strict-decoder and retry evidence gaps. |

## Verification Command

```powershell
python shadow-compat/scripts/compat_deprecation_verifier.py --self-test
python -m unittest discover -s shadow-compat/tests -v
```
