# `shadow-accessibility` — Specialist Evaluation Scenarios

Use these offline evaluation scenarios to grade whether `shadow-accessibility` operates as a **WCAG 2.2 AA/AAA, Assistive-Tech, Cognitive UX & i18n/RTL Engineering Specialist**.

| ID | Scenario Prompt | Expected Specialist Behavior | Fail Red Flags |
| :--- | :--- | :--- | :--- |
| **A11Y-EVAL-01** | *"Tim membangun tombol aksi dengan `<div onClick={handleSave}>Simpan</div>` dan menghilangkan focus ring dengan `outline: none` supaya terlihat bersih."* | Rejects `<div onClick>` and global `outline: none` via `a11y_html_verifier.py` discipline; replaces with native `<button type="button">` and a visible `:focus-visible` `>= 2px` outline (`>= 3:1` contrast) plus `cursor: pointer`, preserving full `Enter`/`Space` keyboard activation. | Keeps `<div onClick>` or removes focus rings without a high-contrast `:focus-visible` indicator. |
| **A11Y-EVAL-02** | *"Modal konfirmasi hapus dibuka lewat tombol di baris ke-12 tabel, tetapi saat pengguna menekan `Tab`, fokus keluar ke halaman belakang, `Escape` tidak menutup modal, dan saat ditutup fokus lompat kembali ke atas halaman."* | Recommends native `<dialog>` (`showModal()`) or a compliant ARIA dialog (`role="dialog"`, `aria-modal="true"`, `aria-labelledby`), traps keyboard focus inside open modal, closes cleanly on `Escape`, and deterministically restores focus back to the exact row-12 trigger button on close. | Suggests adding `tabindex="1"` hacks or ignoring focus restoration after closing the modal. |
| **A11Y-EVAL-03** | *"Form pendaftaran hanya memakai `placeholder="Masukkan email"` tanpa `<label>` dan saat validasi gagal hanya mewarnai border input jadi merah tanpa pesan terhubung."* | Flags placeholder-only labeling and color-only error state; wires explicit `<label for>` (or wrapping `<label>`), `aria-invalid="true"`, `aria-describedby` pointing to plain-language recovery text, moves focus to the first invalid field (or `role="alert"` summary), and verifies via `test_a11y_controls.py` & `a11y_html_verifier.py`. | Leaves placeholder as the sole label or communicates errors only via red border color. |
| **A11Y-EVAL-04** | *"Badge status pesanan hanya menampilkan titik hijau/kuning/merah tanpa teks dan teks abu-abu `#9CA3AF` di atas latar `#FFFFFF` sulit dibaca."* | Computes exact WCAG 2.2 contrast ratio (`#9CA3AF` on `#FFFFFF` = `2.54:1` — FAILS `4.5:1`!), replaces with AA-compliant semantic text token (`>= 4.5:1`, e.g., `#4B5563` = `7.56:1`), and pairs status dots with explicit text labels and distinct icons so color-blind users never rely on hue alone. | Keeps `#9CA3AF` body text or color-only status dots without text/icon redundancy. |
| **A11Y-EVAL-05** | *"Filter produk memperbarui daftar dari 48 menjadi 12 item secara asinkron dan menampilkan toast 'Disimpan', tetapi pengguna NVDA/VoiceOver tidak mendengar pemberitahuan apa pun."* | Adds polite ARIA live regions (`aria-live="polite"` / `role="status"` mounted in DOM before updates) for result counts & confirmations and `role="alert"` (`aria-live="assertive"`) strictly for critical errors, announcing updates without stealing keyboard focus, and records which screen reader was actually tested. | Steals focus abruptly to the toast banner or mounts `aria-live` conditionally at the same tick as text insertion (misses announcement in NVDA/VoiceOver). |
| **A11Y-EVAL-06** | *"Halaman hero memakai animasi parallax agresif dan saat browser di-zoom `200%` teks menumpuk dan muncul scroll horizontal."* | Implements `@media (prefers-reduced-motion: reduce)` disabling parallax and non-essential motion, switches fixed `px` containers to fluid `rem`/`min-width: 0` reflow down to `320px` CSS width (`200%` zoom) with zero horizontal scroll, and enforces `>= 44x44px` mobile touch targets. | Ignores `prefers-reduced-motion` or disables browser pinch-zoom via `user-scalable=no`. |
| **A11Y-EVAL-07** | *"Aplikasi diperluas ke bahasa Indonesia dan Arab (`dir="rtl"`): tombol terpotong di bahasa Indonesia (`+35%` lebih panjang), CSS `margin-left`/`right` hancur di Arab, nomor `+62 812-3456` terbalik, dan switching bahasa mengubah simbol `$100` menjadi `Rp 100`."* | Applies CSS Logical Properties (`margin-inline-start`, `padding-inline`, `text-align: start`), directional icon mirroring (`[dir="rtl"] .icon-directional`), `<bdi>` isolation on phone/SKU/codes, ICU MessageFormat plurals, `Intl.NumberFormat` bound strictly to authoritative ISO-4217 currency code (`USD` != `IDR`), and `+35%` pseudo-localization stress testing. | Uses `margin-left` overrides, hardcodes currency symbol by language instead of transaction currency, or fixes button widths in pixels. |
| **A11Y-EVAL-08** | *"Pengguna lansia/neurodivergent mengeluh kode referensi error di toast hilang dalam 3 detik sebelum sempat dicatat, dan sesi habis tiba-tiba menghapus seluruh isian form pajak yang sudah diketik 15 menit."* | Applies cognitive accessibility principles: keeps error/reference context visible inline (zero memory-burden transitions), warns with 1-click session extension before timeout, preserves typed form drafts across validation failures, uses plain non-blaming recovery copy, and prefers 1-click Undo over repetitive confirmation modals for reversible actions. | Dismisses critical error reference codes automatically in 3 seconds or wipes form inputs on validation/session failure. |
