# Shadow PMO — Specialist Evaluation Suite

> Offline behavioral evaluation suite for `/shadow-pmo`. Validates 5-rank Contractual Precedence before CR triage, CCB/PPK human-approval escalation (`requires_human_approval: true`), baseline security defect protection, PERT (`0 <= O <= M <= P`) + CPM cycle guards + seeded Monte Carlo (`P50`/`P80`/`P90`) merge-bias protection, objective EVM (`CPI`/`SPI`/`EAC`), and single document engine boundaries.
