# `modern-web-guidance` — Specialist Evaluation Scenarios

Use these offline evaluation scenarios to grade whether `modern-web-guidance` champions **Baseline Widely Available native web platform APIs**, **graceful `@supports` progressive enhancement**, **Tailwind v4 interactive craft restoration**, **real LCP/INP/CLS engineering**, and **honest offline fallback without inventing unverified guide IDs**.

| ID | Scenario Prompt | Expected Specialist Behavior | Fail Red Flags |
| :--- | :--- | :--- | :--- |
| **MWG-EVAL-01** | *"Kita butuh modal konfirmasi dan popover dropdown menu di React; install saja 3 library pihak ketiga (`react-modal`, `popper.js`, `body-scroll-lock`) dan pakai `z-index: 99999`."* | Recommends Baseline native HTML `<dialog>` (`showModal()`, `::backdrop`, top-layer stacking, built-in `Escape` & `inert`) and the **Popover API (`popover`, `popovertarget`)**, pairing CSS Anchor Positioning strictly behind `@supports (anchor-name: --a)` progressive fallback for older Safari/Firefox rather than adding 3 legacy packages! | Installs legacy modal/scroll-lock packages and `z-index: 99999` hacks without considering native `<dialog>` and Popover API. |
| **MWG-EVAL-02** | *"Kartu produk dipakai di sidebar sempit (280px) sekaligus di grid utama (900px) — kita pakai `@media (min-width: 768px)` tapi layout kartu di sidebar selalu berantakan."* | Replaces viewport-only `@media` queries with Baseline **CSS Container Queries (`container-type: inline-size`, `@container (min-width: 24rem)`)** and CSS Grid `subgrid` so reusable components adapt cleanly to their actual parent container width. | Hacks hardcoded viewport breakpoints or duplicate card components instead of `@container` queries. |
| **MWG-EVAL-03** | *"Setelah upgrade ke Tailwind CSS v4, semua tombol tidak lagi menampilkan `cursor: pointer` saat hover, dan scroll-driven parallax hero memicu pusing pada pengguna sensitif gerak."* | Restores base-layer interactive affordances (`button:not(:disabled), [role="button"], summary, select:not(:disabled) { cursor: pointer; }` and `:disabled { cursor: not-allowed; }`) with full 5 states (`default/hover/active/:focus-visible/disabled`), AND wraps all scroll/View-Transition motion strictly inside `@media (prefers-reduced-motion: no-preference)`. | Ignores Tailwind v4 button cursor preflight reset or ships mandatory unguarded scroll/parallax animations. |
| **MWG-EVAL-04** | *"Hero banner LCP lambat (`4.6s`) karena gambar hero memakai `loading=\"lazy\"` tanpa `width`/`height` (juga memicu `CLS = 0.28`), sementara klik filter tabel terasa macet (`INP = 480ms`)."* | Fixes all three Core Web Vitals with native web platform primitives: removes `loading="lazy"` on the LCP hero `<img>`, sets `fetchpriority="high"` + explicit `width`/`height` (`aspect-ratio`) + `<link rel="preload" as="image">`, applies `content-visibility: auto` strictly to below-the-fold sections, and chunks heavy JS main-thread filter work via `scheduler.yield()` / `setTimeout(0)` fallback. | Keeps `loading="lazy"` on the LCP hero image or claims `"LCP < 2.5s PASS"` without real measurement! |
| **MWG-EVAL-05** | *"Halaman Next.js App Router memiliki 4 `await fetch()` berurutan di Server Component dan import barrel `import { Icon } from 'lucide-react'` yang membengkakkan client bundle."* | Loads [references/react-nextjs-performance.md](references/react-nextjs-performance.md): eliminates async waterfalls with `Promise.all` / `<Suspense>` streaming boundaries, deduplicates per-request queries with `React.cache()`, avoids barrel re-export bloat via direct imports / `optimizePackageImports`, and keeps heavy formatters server-side. | Leaves sequential `await` waterfalls and client barrel imports untouched. |
| **MWG-EVAL-06** | *"Tolong bantu optimasi query PostgreSQL `EXPLAIN ANALYZE` dan tulis script Python CLI untuk cron backup Docker."* | Respects explicit negative triggers: declines activating `modern-web-guidance` for backend SQL, Docker/CI pipelines, or local Python CLI scripts, routing cleanly to `/shadow-db`, `/shadow-ops`, or `/shadow-data`. | Loads browser CSS/HTML Baseline guidance on a pure backend SQL or Python CLI task. |
