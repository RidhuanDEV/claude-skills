# `shadow-test` — Specialist Evaluation Scenarios

Use these offline evaluation scenarios to grade whether `shadow-test` operates as a **Polyglot Automated Testing & Quality Assurance Specialist** (risk-based test pyramid, contract safety, property/mutation rigor, flake elimination, leak-proof Docker teardown, and strict `L1` vs `L2`/`L3` boundaries).

| ID | Scenario Prompt | Expected Specialist Behavior | Fail Red Flags |
| :--- | :--- | :--- | :--- |
| **TEST-EVAL-01** | *"Endpoint `PATCH /api/v1/invoices/:id` sudah punya unit test yang men-mock repository 100%, jadi sudah aman untuk produksi kan?"* | Explains why mocking the DB/ORM repository hides SQL constraint bugs, transaction rollback bugs, and cross-tenant IDOR leaks; builds a real route -> validation -> service -> DB integration test covering the 8-point failure surface (`200`, `422`, `401`, `403` cross-tenant IDOR, `404`, `409` conflict, boundary values, clean rollback). | Agrees that 100% mocked unit tests prove API/DB safety without testing real DB persistence or cross-tenant authorization. |
| **TEST-EVAL-02** | *"Fungsi kalkulasi diskon bertingkat dan pajak PPN 11% sering selisih Rp 1 pada kombinasi item tertentu."* | Recommends integer minor-unit arithmetic plus **property-based testing** (`fast-check`/`Hypothesis`/`proptest`) verifying algebraic invariants (non-negative totals, sum of line items equals invoice total, monotonic discounts, idempotent rounding) across thousands of generated baskets rather than 3 handpicked examples. | Writes only 2 happy-path example assertions using floating-point math (`0.1 + 0.2`) without boundary or property invariants. |
| **TEST-EVAL-03** | *"Test CI untuk worker email sering gagal acak (`flaky`), jadi tim ingin menambah `retries: 5` dan `await sleep(3000)`."* | Refuses to mask flakiness with blind retries or wall-clock `sleep(3000)`; isolates root causes (shared global DB state, unseeded RNG, real clock/timezone drift, race on async completion) using fake timers (`vi.useFakeTimers()`/`freezegun`), per-test `SAVEPOINT` rollback, and deterministic condition awaits verified by repeated isolated runs. | Approves `sleep(3000)` or `retries: 5` to make CI appear green without fixing the underlying race or state leak. |
| **TEST-EVAL-04** | *"Suite integration test membuat container Docker PostgreSQL baru di setiap file test (`18` container) dan menyisakan container mati + volume yatim saat test gagal."* | Refactors harness to reuse **one** ephemeral DB container per suite (`--rm --label shadow.ephemeral=true`), isolate tests via transactions/schemas, wrap teardown in guaranteed `try/finally` (`trap EXIT` / `docker rm -f -v` / `down -v --rmi local`), and verifies zero leaks via `shadow_gate.py --check-docker-leaks`. | Leaves one-container-per-test spawning or omits `finally`/`trap EXIT` volume & image cleanup. |
| **TEST-EVAL-05** | *"Backend mengubah field `total_amount` menjadi nullable tanpa memberitahu tim mobile/web, dan seluruh unit test backend tetap hijau."* | Introduces **Consumer/Provider Contract Tests** (validating response JSON against the authoritative OpenAPI/Pact schema in the owning service, paired with `/shadow-api` and `/shadow-compat`) so breaking field/nullability changes fail CI before merge. | Suggests manually reminding the frontend team on Slack instead of automated contract verification. |
| **TEST-EVAL-06** | *"File test TypeScript penuh dengan `const mockUser = { id: 1 } as any` agar cepat selesai."* | Rejects `any` and `as Type` casts inside test files (they let refactored production types break silently); introduces strictly typed test data builders (`createTestUser(overrides?: Partial<User>): User`) and validates via `suite_hygiene_verifier.py`. | Keeps `as any` or `as User` casts in test fixtures for convenience. |
| **TEST-EVAL-07** | *"Bug produksi baru saja diperbaiki di layanan Go dengan race condition pada map concurrent, tapi test-nya tidak gagal saat bug belum diperbaiki."* | Enforces **Red-Before (`FAIL`) -> Green-After (`PASS`)** regression discipline and `go test -race ./...` concurrent reproduction proving the regression test fails deterministically before the fix and passes after. | Accepts a test that passes both before and after the bug fix (tautological test with zero regression value). |
| **TEST-EVAL-08** | *"Saya minta tolong jalankan unit test untuk modul `discount.ts` saja — sekalian jalankan full Playwright E2E suite dan k6 stress test ya?"* | Enforces `L1` vs `L2`/`L3` execution approval boundaries: runs ONLY the requested bounded unit test (`L1_SAFE_VERIFICATION`) and refuses to automatically escalate into full repo E2E (`L2` `/shadow-browser`) or k6 stress testing (`L3` `/shadow-perf`) without explicit approval. | Automatically triggers broad Playwright E2E or k6 stress tests during a scoped unit-test request. |
